# 异常输入与边界值清单（接口/模块测试必测方向）

正常路径通过 ≠ 验收通过。每个接口（每个可写参数）都要问三件事：

1. **必填与空值**：缺了、空了、写成 `"null"` 字符串了，会怎样？
2. **类型与格式**：传错类型/格式，是 400 统一错误，还是 500 堆栈/SQL 报错？
3. **边界与超界**：正好等于上限、上限 +1、远超上限、负数/0，会被拒绝、被截断，还是照单全收？

写接口额外问：**非法输入有没有落库**（用列表/详情核对），**重复提交/并发**会怎样。

## 1. 参数变异矩阵

对每个参数按列取 3~5 个，不必全组合；优先必填参数、可写参数、参与 SQL 的字符串参数。

### A. 必填与空值
- [ ] 完全不传该参数（`/list` 不带 `did`、`body` 缺字段）
- [ ] 空字符串 `""`、纯空格 `"   "`
- [ ] 字符串 `"null"` / `"undefined"` / `"NULL"`（区分「空值」与「字面量」）
- [ ] 数字参数传 `0`、`"0"`、`null`
- [ ] 空 body、空 JSON `{}`、`Content-Type` 缺失

期望：必填缺失 → 400/业务错误码 + 明确提示；可空参数传 `""` 应按「未传」处理或报校验错误，**不能**把 `"null"` 当真实值存库。

### B. 类型与格式
- [ ] 字符串参数传数字/布尔/数组/对象/嵌套对象
- [ ] 数字参数传 `"abc"`、`"1.5"`、`true`
- [ ] 日期传 `2026-02-30`、`2026-13-01`、`2026/10/26`、`10/26/2026`、纯时间、时区后缀
- [ ] 枚举传非法值、大小写变体、前后空格
- [ ] JSON body 传数组、字符串、`null`、非 JSON 文本

期望：类型/格式非法 → 400 或统一业务错误码，**不能 500**，不能返回堆栈。

### C. 长度与超界
- [ ] 最短（空）→ 正好上限 → 上限 +1 → 2× 上限
- [ ] 数据库列长度（如 `varchar(64)`）→ 列长 +1
- [ ] 64KB 字符串、超长 URL（>2KB）、超大 body（>1MB）
- [ ] 中文/emoji 按字符还是按字节算长度

期望：超界应被校验拒绝（提示长度限制）；静默截断、数据库报错、500 都算问题。

### D. 数值边界
- [ ] `0`、`-1`、小数、`NaN`、`Infinity`、`1e999`
- [ ] `int` / `long` 最大值、最大值 +1、溢出
- [ ] 分页：`pageNum=0` / `-1` / 超大；`pageSize=0` / `-1` / 超大（10 万）
- [ ] 区间/百分比：负数、超过 100%、下界 > 上界

期望：非法数值被拒绝或有明确默认值；分页超大值应有上限（否则是健壮性/DoS 风险，记录响应大小与耗时）。

### E. 特殊字符与编码
- [ ] 单引号、双引号、反斜杠、`%`、`_`（LIKE 通配）
- [ ] 换行、制表符、控制字符 `\u0000`
- [ ] 中文、emoji、超长 Unicode、非法 UTF-8 字节（URL 编码）
- [ ] 原型链字段：`__proto__`、`constructor`、`prototype`（JSON body）
- [ ] 模板/表达式插值：`${7*7}`、`#{1+1}`、`{{7*7}}`

期望：字符按字面值处理或明确拒绝；不得触发模板/表达式求值；不得导致 500。

### F. 注入与脚本串（**仅测试/开发环境，安全范围内**）
- SQL 注入（只读接口优先）：
  - `' OR '1'='1`
  - `' AND '1'='2`
  - `';--`
  - `1' UNION SELECT NULL--`
  - `%' OR LIKE '%`
- XSS / 脚本：`<script>alert(1)</script>`、`"><img src=x onerror=alert(1)>`
- 禁止使用：`; DROP TABLE`、`WAITFOR DELAY`、`SLEEP()`、堆叠注入、盲注脚本、批量导出。
- 写接口上的注入串可能落脏数据：必须确认测试环境、记录清理方式；优先用只读查询接口验证 SQL 处理。

期望：注入串按**字面值**处理（正常 200/空结果或 400 校验失败），**不能**出现 SQL 报错文本、不能改变查询结果集、不能执行。

### G. 时间与区间
- [ ] `beginTime`/`endTime` 缺一个、缺两个
- [ ] 两端相等（边界包含性）
- [ ] 倒序区间（begin > end）
- [ ] 极值：`0001-01-01`、`9999-12-31`、未来/过去 100 年
- [ ] 格式错误、空串、只有日期没有时间

期望：倒序/空区间返回空集；边界相等按契约包含或排除；格式非法不被当成 SQL 片段执行。

### H. 鉴权与越权
- [ ] 无 token、空 token、坏 token、过期 token
- [ ] header 大小写、`Bearer` 前后空格、重复 Authorization
- [ ] 用 A 账号 token 访问 B 账号的资源（水平越权）
- [ ] 普通用户访问管理端接口（垂直越权）

期望：统一 401/403（或项目统一约定，如 HTTP 200 + `code=401`），不泄漏资源是否存在。

### I. 请求形态
- [ ] 正确参数 + 错误 method（GET 接口 POST 调用）
- [ ] `Content-Type: text/plain` 带 JSON body
- [ ] 重复 query 参数（`?did=a&did=b`）
- [ ] 路径穿越（`../`、`..%2f`）、超长路径
- [ ] 缺少 `Content-Length`、`chunked` body（按需）

期望：明确拒绝（405/400/415）而不是 500。

## 2. 期望与判读

| 现象 | 初判 | 必须补充的证据 |
|---|---|---|
| 必填缺失仍成功 / 写入脏数据 | 产品缺陷（校验缺失） | 写入后列表/详情查询结果 |
| 类型/格式非法 → 500、堆栈、SQL 异常文本 | 产品缺陷（异常处理缺失；可能 SQL 注入面） | 响应体 + 后端日志对应行 |
| `' OR '1'='1` 改变结果集或返回全量 | 高危（SQL 注入） | 同参数正常对照 + 两次响应 |
| 注入串按字面值处理、200/空结果 | 一般正常（记录即可） | 响应体 |
| 超长值静默截断 / 落库截断 | 产品缺陷或契约缺失 | 接口返回 + DB 行长度 |
| `"null"`/`"undefined"` 被当真实值 | 产品缺陷 | 接口返回 + DB |
| 分页 0/-1/超大无上限，响应巨大或超时 | 健壮性缺陷（DoS 风险） | 响应大小、耗时、rows 数 |
| 越权返回他人数据 | 高危（水平/垂直越权） | 两个账号的 token 对照 |
| 错误响应不符合项目统一结构 | 契约缺陷 | 接口文档 / 同类接口对照 |

判定原则：**注入串不报错是好事，报错才是缺陷；异常输入返回 500 一律按缺陷处理**（除非契约明确写了会 500）。

## 3. 断言写法（`ft_http_run`）

```json
{
  "expect": {
    "status": [200, 400, 401, 403],
    "jsonPath": [
      { "path": "$.code", "op": "in", "value": [200, 400, 401, 403, 50001] },
      { "path": "$.msg", "op": "notMatches", "value": "SQLException|syntax error|BadSqlGrammar|stack trace|at com\\." },
      { "path": "$.total", "op": "equals", "value": 0 }
    ]
  }
}
```

- 「不能 500」用 `status` 白名单表达；`500` 不在列表里，命中即失败
- 「不能泄漏 SQL/堆栈」用 `notMatches` / `notContains`（v0.2.0 起支持）
- 边界包含性用 `gte`/`lte`；长度用 `length`/`lengthGte`/`lengthLte`；枚举用 `in`
- 分页超界这类「观察项」不要写死断言，记录 `rows` 数量与 `latencyMs`，在报告里说明

## 4. 执行顺序与安全

1. 先只读接口（GET）过矩阵，再写接口；写接口前确认测试环境、记录将写入的数据与清理方式。
2. 写接口的非法输入用例通常**不应产生数据**：跑完用列表/详情核对总数与最新记录。
3. 注入/脚本 payload 只用于测试/开发环境；不做破坏性语句、不遍历、不外带数据、不压测。
4. 同一参数的多条异常用例集中在一次 run 里，主题命名 `negative-<module>`，便于归档与复跑。
5. 触发风控/锁号的参数（如错误密码、验证码）单独说明并限制次数。

## 5. UI 侧（模块测试时）

- [ ] 必填项留空提交 → 前端拦截 + 后端兜底
- [ ] 超长文本粘贴、特殊字符、emoji → 显示不炸、不截断丢字
- [ ] 数字输入框填负数/小数/字母 → 前端限制
- [ ] XSS 串在列表中**原样转义显示**，不执行
- [ ] 后端拒绝时，页面提示与接口错误信息一致
