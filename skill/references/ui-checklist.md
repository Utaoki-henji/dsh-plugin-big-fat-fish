# UI 用例设计清单（Vue 页面）

## 1. 页面与导航
- [ ] 路由可直接访问、刷新不 404
- [ ] 菜单/面包屑跳转正确
- [ ] 无权限路由被拦截
- [ ] 浏览器返回/前进状态正确

## 2. 表单
- [ ] 必填校验提示
- [ ] 字段格式校验（手机号、邮箱、长度）
- [ ] 提交中防重复点击
- [ ] 提交成功提示 + 列表刷新
- [ ] 提交失败提示可读，表单内容保留
- [ ] 重置/取消行为

## 3. 列表与查询
- [ ] 首屏加载、空状态、加载中、错误状态
- [ ] 分页、跳页、每页条数
- [ ] 筛选条件组合与重置
- [ ] 排序
- [ ] 删除二次确认

## 4. 交互与反馈
- [ ] 按钮禁用/可用状态
- [ ] 弹窗打开/关闭、Esc 关闭
- [ ] 消息提示（成功/失败）出现且自动消失
- [ ] 加载骨架/loading
- [ ] 长文本、超长列表不撑破布局

## 5. 数据一致性
- [ ] 新增后列表/详情立即可见
- [ ] 编辑后回显正确
- [ ] 删除后列表不再出现
- [ ] 刷新页面后数据一致（不依赖前端内存）

## 6. 异常与网络
- [ ] 接口 4xx/5xx 时的用户提示
- [ ] 网络断开/超时提示
- [ ] 重复提交/快速点击

## 7. 兼容与可访问性（按需）
- [ ] 常见分辨率（1440/1280）
- [ ] 键盘 Tab 可操作关键流程
- [ ] 控制台无报错（失败的 XHR 与 console error 会被采集）
